# فيديو مصيف العائلات (Remotion)

فيديو عمودي 1080×1920، مدّته دقيقتان، 30 إطاراً في الثانية.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح هذا المجلد في الطرفية (أو في Claude Code) واكتب:
   npm install
3. للمعاينة والتعديل في المتصفح:
   npm start
4. لتصدير الفيديو (يُحفظ في out/masif-al-aailat.mp4):
   npm run render

## الملفات
- src/index.jsx : تسجيل الفيديو (المقاس والمدة)
- src/Main.jsx  : ترتيب المشاهد، توقيت كل قطع (cuts)، الانتقالات، الشعار، شريط التقدّم، الصوت والخطوط
- src/scenes.jsx: المشاهد الـ16 (S1 ... S16) ونصوصها
- src/lib.jsx   : الألوان، حركات الكتابة، البطاقات، الأشكال في الخلفية
- public/       : الشعار logo.png، الصوت audio.m4a، الخط Tajawal

## تعديلات سريعة
- تغيير نص: ابحث عنه في src/scenes.jsx وغيّره.
- تغيير الألوان: الكائن C في أعلى src/lib.jsx.
- تغيير توقيت المشاهد: المصفوفة cuts في src/Main.jsx (بالإطارات، 30 = ثانية واحدة).
- تغيير نوع الانتقال: المصفوفة trans في src/Main.jsx
  (circle, circle2, diag, diag2, blinds, blindsV, diamond, zoom, split, flip, slideUp).

## تحسينات النسخة الاحترافية
- تنظيف الشعار `public/logo.png` من خطوط الشبكة، وإخفاء فواصل القطع في مشهد البداية بعد اكتمال تركيب الشعار.
- طبقة تشطيب في `src/finish.jsx`: إضاءة ذهبية دافئة متطايرة، شريط بحر متحرك أسفل الشاشة، تدرّج لوني مع تعتيم الأطراف وحبيبات سينمائية خفيفة.
- خلفيات أهدأ (تقليل شفافية الأشكال الهندسية) لإبراز النصوص.
- إعادة توزيع محتوى المشاهد 2 و3 و4 و5 و9 عمودياً لملء الفراغ السفلي.
- تلاشٍ ناعم للصوت في البداية والنهاية.
- التوقيت والنصوص والصوت كما هي دون تغيير.

## المؤثرات الصوتية والشعار ثلاثي الأبعاد
- لكل تغيير صفحة صوت مختلف (whoosh، ورق، pop، chime، impact، shimmer...) مع مؤثرات داخل بعض المشاهد (ختم «رفض آلي» و«مقبول»، تركيب الشعار).
  القائمة والتوقيت ومستوى الصوت في المصفوفة `sfx` داخل `src/Main.jsx`.
- الأصوات مولّدة برمجياً: `python3 scripts/make_sfx.py` ينشئها في `public/sfx/`.
- الشعار ثلاثي الأبعاد في الخاتمة: `src/logo3d.jsx` (لوح ذهبي بسماكة حقيقية ولمعان معدني)،
  ويستعمل `public/logo-emblem.png` الذي ينشئه `python3 scripts/make_emblem.py`.
